# Tillson T3 Moving Average

Created by Tim Tillson, the [T3](https://forex-station.com/download/file.php?id=3407929) indicator is a smooth moving average that reduces both lag and overshooting.
[[Discuss] &#128172;](https://github.com/facioquo/stock-indicators-dotnet/discussions/332 "Community discussion about this indicator")

```csharp
// C# usage syntax
IReadOnlyList<T3Result> results =
  bars.ToT3(lookbackPeriods, volumeFactor);
```

:::

::: buffer
Create a buffer list and add each bar as it arrives:

```csharp
T3List t3List = new(lookbackPeriods, volumeFactor);

// call from your WebSocket or SSE message handler
void OnBarReceived(IBar bar) => t3List.Add(bar);

// the list itself holds the results; fills as the handler runs
IReadOnlyList<T3Result> results = t3List;
```

See [Buffer lists](/guide/styles/buffer) for the full usage guide.
:::

::: stream
Subscribe to a `BarHub` and add each bar as it arrives:

```csharp
BarHub barHub = new();
T3Hub observer = barHub.ToT3Hub(lookbackPeriods, volumeFactor);

// call from your WebSocket or SSE message handler
void OnBarReceived(IBar bar) => barHub.Add(bar);

// results fill as the handler runs
IReadOnlyList<T3Result> results = observer.Results;
```

See [Stream hubs](/guide/styles/stream) for the full usage guide.
:::

## Parameters

| param | description |
| ----- | ----------- |
| `lookbackPeriods`<br>_`int`_ | Number of periods (`N`) for the EMA smoothing.  Must be greater than 0 and is usually less than 63.  Default is 5. |
| `volumeFactor`<br>_`double`_ | Size of the Volume Factor.  Must be greater than 0 and is usually less than 2.  Default is 0.7 |

### Historical price bars requirements

You must have at least `6×(N-1)+100` periods of `bars` to cover the [warmup and convergence](https://github.com/facioquo/stock-indicators-dotnet/discussions/688) periods.  Since this uses a smoothing technique, we recommend you use at least `6×(N-1)+250` data points prior to the intended usage date for better precision.

`bars` is a collection of generic `TBar` historical price bars.  It should have a consistent frequency (day, hour, minute, etc).  See [the Guide](/guide/getting-started#historical-bars) for more information.

## Response

::: series

```csharp
IReadOnlyList<T3Result>
```

- This method returns a time series of all available indicator values for the `bars` provided.
- It always returns the same number of elements as there are in the historical price bars.
- It does not return a single incremental indicator value.
:::

::: buffer

```csharp
T3List : IReadOnlyList<T3Result>
```

- The list itself holds the results, one for each bar or value added, in timestamp order.
- It keeps up to 100,000 results by default and drops the oldest beyond that; set `MaxListSize` to keep fewer.
:::

::: stream

```csharp
IReadOnlyList<T3Result> results = observer.Results;
```

- `observer.Results` holds the results, one for each bar in the `BarHub` cache, in timestamp order.
- Results update as bars arrive, including bars that arrive late or are revised.
- The cache keeps up to 100,000 results by default; set `maxCacheSize` on the `BarHub` to keep fewer.
:::

::: warning 🚩 ⚞ Convergence warning
The first `6×(N-1)+250` periods will have decreasing magnitude, convergence-related precision errors that can be as high as ~5% deviation in indicator values for earlier periods.
:::

### T3Result

| property | description |
| ----- | ----------- |
| `Timestamp`<br>_`DateTime`_ | Date from evaluated `TBar` |
| `T3`<br>_`double?`_ | T3 Moving Average |

## Chaining

::: series
This indicator may be generated from any chain-enabled indicator or method.

```csharp
// example
var results = bars
    .Use(CandlePart.HL2)
    .ToT3(..);
```

Results can be further processed on `T3` with additional chain-enabled indicators.

```csharp
// example
var results = bars
    .ToT3(..)
    .ToRsi(..);
```

See [Chaining indicators](/guide/chaining) for more.
:::

::: buffer
This indicator may be generated from results of another chain-enabled buffer list.  Add each new result to it yourself.

```csharp
// example
SmaList smaList = new(..);
T3List t3List = new(..);

void OnBarReceived(IBar bar)
{
    smaList.Add(bar);
    t3List.Add(smaList[^1]);
}
```

Add each new result to another chain-enabled buffer list to process `T3` further.

```csharp
// example
T3List t3List = new(..);
RsiList rsiList = new(..);

void OnBarReceived(IBar bar)
{
    t3List.Add(bar);
    rsiList.Add(t3List[^1]);
}
```

See [Chaining buffer lists](/guide/styles/buffer#chaining-indicators) for more.
:::

::: stream
This indicator may be subscribed to any chain-enabled hub.

```csharp
// example
T3Hub observer = barHub
    .ToBarPartHub(CandlePart.HL2)
    .ToT3Hub(..);
```

Subscribe other chain-enabled hubs to it to process `T3` further.

```csharp
// example
RsiHub observer = barHub
    .ToT3Hub(..)
    .ToRsiHub(..);
```

See [Chaining stream hubs](/guide/styles/stream#chaining-indicators) for more.
:::
